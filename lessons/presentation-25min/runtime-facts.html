Available Tools

  • Tool Name: key_word_search
  • Description: Searches for a specified keyword across all files in a project
  • Parameters: keyword (directory comes from roots/list or the elicitation, not a tool arg)
  • UI: _meta.ui.resourceUri → ui://keyword-search/mcp-app.html
  • Task support: execution.taskSupport = "optional"

Available Prompts

  • Prompt Name: search_keyword
  • Description: Creates a prompt to search for a word using the key_word_search tool
  • Arguments: keyword (required)

Available Resources

  • Javadoc: 60+ HTML files
  • Example: javadoc/com/workshop/mcp/spec/Capability.html
  • MCP App: ui://keyword-search/mcp-app.html served as text/html;profile=mcp-app
  • Pagination: ✓ (nextCursor: "pageNext")

Elicitation Details

  • Method: elicitation/create
  • Request ID: -4000 (reserved, server-initiated)
  • Trigger: first tools/call while roots are empty
  • Schema Fields: directory (absolute path)
  • Action: accept → directory added to roots, parked call resumed

Task Details

  • Augmentation: tools/call + task: {ttl: 60000}
  • Immediate reply: CreateTaskResult, status working
  • Poll interval: 1000 ms
  • Push: notifications/tasks/status on completion
  • Correlation: _meta.io.modelcontextprotocol/related-task

Session Flow

  • 1. Initialization handshake (2025‑11‑25)
  • 2. notifications/initialized
  • 3. Roots discovery — returns empty
  • 4. Tools discovery
  • 5. tools/call — deferred
  • 6. Elicitation — user picks a directory
  • 7. Parked call resumed, results returned
  • 8. Task-augmented tools/call
  • 9. tasks/get — working
  • 10. Status notification — completed
  • 11. tasks/result — real result
  • 12. tasks/list, then shutdown
