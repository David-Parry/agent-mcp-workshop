About This Traffic

Everything on these pages comes from real captured traffic:

  • Client: inspector-cli v2.5.0 (MCP Inspector)
  • Server: agent-mcp-workshop v0.0.1 (Java, stdio transport)
  • Protocol: MCP 2026-07-28 — stateless: no handshake, no session
  • Duration: ~50 seconds (17:55:28 – 17:56:16)

In under a minute it exercises:

  • Discovery: server/discover — supported revisions, capabilities, and identity, with no session created
  • Reads: 60+ Javadoc resources, prompts, and tools — all cacheable, so all carrying ttlMs and cacheScope
  • Round trips: a tools/call answered with input_required, then re-sent by the client with the answer
  • MCP Apps: a tool advertising _meta.ui.resourceUri plus its ui:// HTML resource
  • Tasks: a task handle the server chose to return, a status notification, and polling to completion
  • Rejections: the removed initialize at -32601, plus -32022 and -32602 for a bad envelope

Server capabilities advertised: completions, prompts, resources, tools, and extensions (io.modelcontextprotocol/ui, io.modelcontextprotocol/tasks). Client side, repeated on every single request: elicitation and the same two extensions — plus a deprecated roots that real clients still send and this server ignores.
