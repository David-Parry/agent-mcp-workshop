⌨️ IDE Demo — 20–23 min

Launch MCP Inspector — See This Flow Live

  • In the IDE terminal: ./gradlew build to build the server JAR
  • Launch Inspector: npx @modelcontextprotocol/inspector java -jar build/libs/agent-mcp-workshop-0.0.1.jar
  • Open the Inspector URL in your browser — click Connect
  • Watch the server/discover probe go out first, with the string id server-discover-probe-1 — an answer is how the client learns this server speaks the stateless lifecycle (steps 1–2 above)
  • There is no third message: no notifications/initialized, no session. Expand any later request and find the whole envelope repeated in params._meta
  • Or skip the UI and run the two probe scripts: inspector/modern-probe.sh (discovery + the removed methods) and inspector/modern-mrtr.sh (both MRTR paths)
  • Compare the live message trace with the Trace Log reference page
