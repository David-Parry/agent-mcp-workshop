This is the complete 2026-07-28 lifecycle: discovery, stateless requests, the Multi Round-Trip Requests loop, the task poll loop, and a subscription. There is no initialize, no notifications/initialized, and no ping — all three were removed, and a client that sends one gets -32601.

Why the shape changed

Read top to bottom, the diagram is really one idea applied three times: the session is gone, so every fact has to travel on the wire.

  • The handshake became an envelope. A session is a piece of memory pinned to one process. Pin nothing, and any instance behind a load balancer can answer any request — that is the horizontal-scaling argument. It also means a result can be cached and replayed, which is why ttlMs and cacheScope appear at all.
  • Server-initiated requests became embedded requests. Without a session there is no correlated channel to send a request back down, and modern clients simply discard inbound requests. So the three things a server used to ask for — roots/list, sampling/createMessage, elicitation/create — now ride inside an input_required result, and the answer arrives on a fresh tools/call. This server embeds exactly one of them, elicitation/create: roots and sampling are both deprecated under SEP-2577, and directories now reach the search tool as a tool parameter instead.
  • The parked request became requestState. The old server remembered "I am halfway through call id 4". The new one cannot, so it hands that memory to the client as an opaque string and reads it back off the retry. Continuation state moved from the server's heap onto the wire.

Chapter 3: Bring Discovery and the Envelope to Life

The first two arrows of this diagram — server/discover → server/discover result — are exactly what the Chapter 3 demo makes real. Switch to the IDE and follow the full script on the Capabilities page: walk SERVER_DISCOVER and envelopeFor() in IORouter, launch MCP Inspector, and watch these messages appear live. Keep the Trace Log open to compare against Inspector's message pane.

Before you connect: the Inspector still defaults to the legacy handshake. Add "protocolEra": "modern" beside command/args/env in the server's entry in inspector/config.json, or the very first message on the wire will be an initialize that this server answers with -32601.
